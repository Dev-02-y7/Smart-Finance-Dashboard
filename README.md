Smart Finance Dashboard

A personal finance dashboard built to practice frontend development and real-world problem solving. 
The application allows users to manage income sources, track expenses, and monitor their spending activity through an interactive dashboard.

Features -

- Add multiple income sources
- Track expenses dynamically
- Real-time balance calculations
- Spending overview dashboard
- Currency selection support
- Responsive modern UI
- Interactive user experience

What I Learned -

While building this project, I improved my understanding of how larger frontend applications manage and update data dynamically in real time. I improved my JavaScript problem-solving skills while working with financial calculations, interactive UI components, and user-focused dashboard design.
I also gained experience structuring frontend logic more efficiently, debugging application behavior, and creating a smoother user experience similar to modern finance and fintech platforms.

I wanted to create something more practical than a basic beginner project. Instead of just displaying data, I focused on building an application that simulates how real finance dashboards work and update information dynamically.
